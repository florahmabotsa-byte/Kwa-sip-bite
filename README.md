Kwa Sip & Bite – Part 3

Project Overview

Kwa Sip & Bite is a restaurant website designed to showcase the restaurant's food, drinks, services and contact information. Part 3 builds on the website developed in Part 2 by introducing JavaScript functionality, form validation and improved user interaction.

Changes and Improvements from Part 2 to Part 3

The following improvements and features were implemented:

1. JavaScript Integration

- Created and updated the "script.js" file.
- Linked the JavaScript file to the website's HTML pages.
- Added interactive functionality to improve the user experience.

2. Menu Functionality

- Added menu search functionality.
- Added category filtering so users can browse different food and drink categories.
- Added price sorting functionality.

3. Gallery Functionality

- Added image enlargement functionality to allow users to view gallery images more clearly.

4. Order Form Validation

- Added validation for customer full names.
- Added South African mobile number validation.
- Added meal selection validation.
- Added quantity validation.
- Added special instructions support.
- Added a Sunday-only availability restriction for Seafood Boil.

5. Automatic Price Calculation

- Added a JavaScript price list based on the restaurant's actual menu prices.
- Added automatic calculation of order totals based on selected meals and quantities.
- Added an order summary displaying customer details, selected meal, quantity, unit price and total cost.

6. Contact Form Validation

- Added full name validation.
- Added email address validation.
- Added message validation.
- Added a confirmation message after successful form submission.

7. SEO Improvements

- Added page titles, meta descriptions and keywords to improve search engine visibility.

Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub

Main Project Files

- "index.html" – Home page
- "about.html" – About Us page
- "menu.html" – Restaurant menu
- "gallery.html" – Food and restaurant gallery
- "contact.html" – Contact information and contact form
- "order.html" – Customer order form
- "style.css" – Website styling
- "script.js" – JavaScript functionality

Conclusion

Part 3 improved the Kwa Sip & Bite website by adding JavaScript functionality, interactive menu features, form validation and automatic order price calculations. These improvements make the website more interactive, user-friendly and functional compared to Part 2.
